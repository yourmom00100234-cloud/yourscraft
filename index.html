화면을 터치하거나 클릭하여 시작하세요!

💻 PC 조작법

  • • WASD : 이동
  • • Shift : 앉기 (절벽 추락 방지)
  • • Space : 점프 / 수영하기
  • • 마우스 좌클릭 : 블록 파괴
  • • 마우스 우클릭 : 블록 설치
  • • 1-6 / 휠 : 블록 선택

📱 모바일 조작법

  • • 좌측 패드 : 이동
  • • 우측 화면 drag : 시점 회전
  • • 우측 버튼 : 점프, 파괴, 설치, 앉기
  • • 하단 슬롯 : 블록 터치 선택

클릭하면 바로 시작됩니다!
